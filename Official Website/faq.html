Frequently asked questions

The questions people actually ask, including the ones that would be uncomfortable to answer honestly.

Is Novaris really Chrome, or a rebrand of it?

It uses Chromium, the same rendering engine Chrome is built on. What Novaris changes is everything around it: which network requests are allowed, what is written to disk, and what a website is told about you. Describing it as a Chromium browser is honest; claiming to be Chrome would not be.

Does the application send anything to Google?

No. We measured rather than trusting the configuration: a Chromium network log over a real session visiting three unrelated sites recorded 39 requests to exactly three hosts, all of them page content. No telemetry, no Safe Browsing pings, no component updater, no variations service, no autofill upload.

This website is a separate thing and does carry advertising, with your consent. The page explaining why sets out the distinction honestly, including the part of it that is uncomfortable.

What happens to my passwords?

You choose whether to move them. Novaris never reads a Chrome or Edge password database on its own, and importing is a deliberate step where you review what comes across.

Once saved, each credential is sealed individually with AES-256-GCM under a key derived from your browser password using Argon2id, and is only ever filled back into the exact host it was saved for. A lookalike sign-in page is refused outright rather than offered the password.

Can support recover my vault if I forget the password?

No. There is no reset link, no recovery code emailed to an address, and no back door. The only supported route resets the vault and destroys its contents.

This is deliberate. A support process that can reset a vault is a support process that can open one, and the two cannot be separated. If that trade is not one you would make, Novaris is not the right browser for you, and that is a legitimate reason to say so.

Is there an account or a subscription?

No account, and nothing to pay for. There is no server component, which is also why there is nothing to sign in to.

Will it force an update on me?

It asks first and shows the download size before anything is fetched. Every release publishes a SHA-512 hash, and the app verifies the installer against it before installing. Uninstalling removes your profile entirely, so the next install is a genuine clean start.

Can I use my Chrome or Edge extensions?

Manifest V2 extensions work: content scripts, background pages and webRequest based blocking all function.

Most current extensions are Manifest V3, whose background logic runs in a service worker. Novaris cannot run those, which is a limit of the engine rather than a setting. Google also offers no install API to third-party browsers, so there is no honest way to make "Add to Chrome" work here.

What Novaris does instead is detect the problem from the manifest, warn you before you install, and label the extension afterwards. An extension that appears installed and quietly does nothing is worse than one you were told about in advance.

Does the ad blocker ever break websites?

The default level blocks advertising networks only, which is rarely something a site actually depends on. Breakage is possible at the strict level, which is exactly why it is opt-in rather than the default.

A live counter shows what was blocked, how many requests, and which host was responsible. An ad blocker you cannot audit is a box you have been asked to trust.

What can still see me, if the site is not on a list?

Two things, and both are stated plainly rather than buried.

A site can obtain your public IP address through WebRTC if it configures a STUN server, with no permission prompt. We tested Chromium's own three mechanisms for preventing this and none of them worked, so we do not claim otherwise. The mitigations that do work are a network-level anonymiser or an extension that removes WebRTC.

Your local network address is usually hidden by Chromium's anonymisation of local addresses, and we verified it is in the packaged build. A site that wants to know where you are can still see the country your connection appears to originate from, because that is inherent to using the internet.

What do the phishing checks actually catch?

Hostname impersonation: addresses that imitate a brand through lookalike characters, digits standing in for letters, internationalised domains, or a real brand parked in front of somebody else's address.

It is not a reputation service, so a brand-new malicious domain with an unusual name can still get through. That is the honest limit, and it is why the Trust Card shows the reasoning rather than a bare verdict.

Why does this website have ads when the browser is about privacy?

The project is free, has no accounts and cannot be funded by selling data it does not have. So the website carries advertising, and says so plainly. Ads load only after you allow them, and the application contains none.

The full reasoning also explains why we think that is a defensible line rather than a comfortable one.

Does it work on Mac or Linux?

Not yet. Novaris is Windows-only. Parts of it depend on Windows cryptography and the Windows credential store, so a Mac or Linux version would be a different project rather than a recompile, and we would rather do one thing properly.

How do I get rid of Novaris completely?

Uninstall it. The installer removes your profile, including history, bookmarks and the vault, so nothing is left behind. If a crash ever prevents a clean uninstall, the profile folder is in your Windows user profile under Novaris and can be deleted directly.
