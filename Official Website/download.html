Before you install

1 Your passwords stay put

Novaris never reads a Chrome or Edge password database on its own. Importing is something you start yourself, and you see what comes across before it is saved.

2 Nothing is uploaded

There is no account to create and no server to talk to. Profile data, including the vault, lives in your Windows profile folder and nowhere else.

3 Your other browser is untouched

Installing does not change your default browser. Novaris offers to become the default only when you ask it to, and you can decline and keep using both.
