About this project

Last updated: 27 September 2026

Novaris is an independent browser for Windows. It is free, has no accounts, and does not collect anything about you. Those three properties are not marketing positioning; they are consequences of a specific technical decision, and everything else on this site follows from them.

Why it exists

Modern browsers have drifted towards being platforms that happen to render web pages. The default is now an account, a sync service, a store, a wallet, a news feed, a VPN upsell, and a steady stream of sponsored results, all of which require the vendor to know who you are.

There is a version of a browser that is just a browser: it renders pages, it keeps your passwords, it blocks adverts because that is what a browser should do, and it has no account for you to be tracked through because it never needed one. Novaris is that, built properly rather than assembled from parts.

What it is built on

Chromium, the open-source engine behind Chrome, Microsoft Edge and most other modern browsers. Writing a rendering engine from scratch would be a decade of work and would be worse at rendering the web than the one Google maintains.

Novaris wraps it in Electron, which is the layer that lets an ordinary web application drive a Chromium instance. The consequence is specific and worth stating: some things Chrome can do, Novaris cannot, because they belong to Chrome's interface rather than to the engine. The most visible is installing extensions from the Chrome Web Store, which depends on a private integration Google offers only to browsers with its own distribution. We do not pretend to have it.

Everything else — blocking, the vault, scam detection, tabs, privacy modes — is ours, and none of it is a setting exposed by Chromium that we simply turned on.

What it will not do

  • No accounts. There is nowhere for your data to be uploaded to, which is the single most valuable property this project has.
  • No telemetry. Not a switch to disable, because the code was never written.
  • No default-on encryption of your history. If you want your history unreadable to us, keep it off your disk where it belongs.
  • No selling your attention inside the browser. The application has no advertising, ever. The website does, and explains it.
  • No "continue without unlocking". A hard lock is the only kind that means anything.

How things get tested

A browser feature that appears to work and quietly does not is the worst possible outcome, and two of the bugs we found would have shipped that way. So the rule is that claims are verified against the packaged build, not against a developer's copy.

  • Unit tests cover the parts that can be isolated, including cryptographic correctness and the parsers that decide what is a phishing address.
  • End-to-end tests drive the real packaged application through a debugging protocol: opening private windows, loading a playing video, transferring a tab over a real socket, checking that a credential is refused on the wrong host.
  • Every release is verified by recomputing the SHA-512 of the installer and comparing it with the published manifest, because an update that cannot be verified is an update that cannot be trusted.

When something turns out not to work, it gets removed and written up rather than shipped behind a label. The security page describes two features we built, measured, found did nothing, and deleted, including one security switch that was actively misleading.

Where it is going

Features that compound: a better tab system, more honest site information, and continued work on the parts that are genuinely hard. Features we have decided against are listed on the limits page, because a project that only tracks towards its next feature will eventually ship something dishonest to get there.

If you want to help and have a Windows machine, the most useful contribution costs nothing: install it, use it for a week, and report what broke. Real usage finds real bugs. If you would rather fund it, the donation page explains exactly where the money goes.
